# Digital SAT Reading & Writing Suite — August 2026 Asia Variants (216 Questions)

An authentic, modern interactive web application containing all **216 Digital SAT Reading & Writing questions** extracted from the official **August 2026 Asia** variant test forms (Variants 1, 2, 3, and 4), featuring a PsychSAT-inspired aesthetic with Remielle Dan's wings, Miyabi's ears, Cissia's tail, and the authentic College Board 2-module timed exam experience with 200–800 scaled scoring.

🌐 **Live Demo (GitHub Pages)**: [https://elshod-gosling.github.io/sat-august-2026-asia-variants/](https://elshod-gosling.github.io/sat-august-2026-asia-variants/)

---

## 🎯 Features

### 🌌 PsychSAT Design System & Custom Artwork
- **Obsidian Dark / Clean Light Mode**: Deep dark palette (#08090e) with electric violet and lilac neon accents (#8b5cf6, #c4b5fd).
- **Remielle Dan's Wings**: Ambient levitating backdrop visual with ethereal glow.
- **Miyabi's Ears**: Top navbar badge emblem and footer decorative element.
- **Cissia's Tail**: Playful animated mascot swaying along the 216-question Master Suite card.
- **Score Ruler**: Dynamic target score ruler (600 → 680 → 740 → 800 MAX).

### ⏱️ Official SAT 2-Module Timed Exam & 200–800 Grading
- **Authentic 2-Module Structure**:
  - **Module 1**: 27 Questions, 32-minute countdown timer.
  - **Inter-Module Break**: Official SAT transition dialog summarizing answered/unanswered/flagged questions before locking Module 1.
  - **Module 2**: 27 Questions, 32-minute countdown timer.
- **Official 200–800 Scaled Scoring**:
  - Non-adaptive equating curve mapping raw correct score (0–54) directly to the College Board 200–800 scale (e.g., 54 = 800, 50 = 750, 40 = 640, 27 = 510).
  - Domain mastery breakdown and percentile bands in the comprehensive score report.

### 📚 Complete Content & Bluebook Testing Tools
- **Full August 2026 Asia Master Suite**: Practice all 216 questions sequentially across all 4 test forms.
- **Individual Variant Testing**: Variants 1, 2, 3, and 4 available as complete 54-question 2-module exams or individual modules.
- **Dual Modes**: Practice Mode (instant check answer with detailed rationales) and Official SAT Exam Mode.
- **Highlighter Toolbar**: Yellow, Pink, and Cyan text highlighting with an instant removal tool and floating popover.
- **Answer Elimination**: Strikethrough (ABC) tool to rule out incorrect choices.
- **Question Navigator**: 27 / 54 / 216 question palette modal with status filtering.
- **Visual Evidence & Figures**: Embedded high-resolution bar charts, data tables, and figures for all 23 quantitative reasoning questions.
- **Keyboard Shortcuts**:
  - ← / →: Previous / Next question
  - A, B, C, D or 1, 2, 3, 4: Select answer choice
  - Enter: Check Answer (in Practice Mode)
  - M: Toggle Mark for Review flag
