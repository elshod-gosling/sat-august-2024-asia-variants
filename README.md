# Digital SAT Reading & Writing Suite — August 26 Asia Variants (216 Questions)

An authentic, modern interactive web application containing all **216 Digital SAT Reading & Writing questions** extracted from the official **August 26 Asia** variant test forms (Variants 1, 2, 3, and 4), complete with passages, figures, question stems, choices, verified answer keys, and detailed pedagogical rationales.

🌐 **Live Demo (GitHub Pages)**: [https://elshod-gosling.github.io/sat-august-2026-asia-variants/](https://elshod-gosling.github.io/sat-august-2026-asia-variants/)

---

## 🎯 Features

- **Home Hub / Practice Modules**:
  - **Full August Asia Master Suite**: Practice all 216 questions sequentially across all 4 test forms.
  - **Variant 1 (Aug 26 Asia Form 1)**: Full 54 Questions, Module 1 (1–27), Module 2 (28–54).
  - **Variant 2 (Aug 26 Asia Form 2)**: Full 54 Questions, Module 1 (1–27), Module 2 (28–54).
  - **Variant 3 (Aug 26 Asia Form 3)**: Full 54 Questions, Module 1 (1–27), Module 2 (28–54).
  - **Variant 4 (Aug 26 Asia Form 4)**: Full 54 Questions, Module 1 (1–27), Module 2 (28–54).
  - **Skill Focus Volumes**: Standard English Conventions, Words in Context, Logical Transitions, Charts & Quantitative Evidence, Inferences & Conclusions, Text Structure & Purpose, Textual Evidence, and Rhetorical Synthesis.
  - **Resume Session**: Automatically picks up where you left off.
- **Check Answer Workflow**: In Practice Mode, select any choice freely and click **"Check Answer"** (or press `Enter`) to validate your choice, reveal detailed rationales, and see why each answer is correct or incorrect.
- **Exam Mode**: Simulates real test conditions with timed tracking, silent answering, and a complete performance score report with domain mastery bar charts.
- **Visual Evidence & Figures**: Embedded high-resolution bar charts, data tables, and figures for all 23 quantitative reasoning questions.
- **Highlighter Toolbar**: Yellow, Pink, and Cyan text highlighting with an instant removal tool and floating popover.
- **Answer Elimination**: Strikethrough (`ABC`) tool to rule out incorrect choices.
- **Question Navigator**: 216-question modal palette with instant filtering by status (`All`, `Unanswered`, `Flagged`, `Incorrect`).
- **Dark & Light Mode**: Clean, eye-friendly themes that persist across reloads.
- **Keyboard Shortcuts**:
  - `←` / `→`: Previous / Next question
  - `A`, `B`, `C`, `D` or `1`, `2`, `3`, `4`: Select answer choice
  - `Enter`: Check Answer (in Practice Mode)
  - `M`: Toggle Mark for Review flag
